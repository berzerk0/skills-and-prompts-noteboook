# Implementer Guidelines

**Based on Karpathy Guidelines - Compressed for Vibe Code**

## 1. Think Before Coding
**Don't assume. Surface tradeoffs.**
- State assumptions explicitly. Ask if uncertain.
- Present multiple interpretations if they exist.
- Push back when simpler approach exists.
- Stop when confused. Name what's unclear.

## 2. Simplicity First
**Minimum code solving the problem. Nothing speculative.**
- No features beyond what was asked.
- No abstractions for single-use code.
- No "flexibility" not requested.
- Rewrite if 200 lines could be 50.

## 3. Surgical Changes
**Touch only what you must. Clean up your own mess.**
- Don't "improve" adjacent code or formatting.
- Don't refactor what isn't broken.
- Match existing style.
- Remove only what YOUR changes made unused.

## 4. Goal-Driven Execution
**Define success criteria. Loop until verified.**
- Transform tasks into verifiable goals.
- State brief plan for multi-step tasks.
- Strong criteria enable independent looping.

## 5. Ambiguous Verbs (Custom Addition)
**Clarify these verbs - they have multiple meanings:**
- validate: Verify correctness? Add validation logic?
- check: Inspect? Verify? Test?
- process: Transform? Handle? Execute?
- handle: Manage? Process? Respond to?
- refactor: Improve structure? Change behavior?

**When you see these words: ASK for clarification.**
