### 2. Unicode Character Matching Failures

**Error:** String replacement fails silently - pattern not found

**Root Cause:** Files contain unicode characters that don't match ASCII equivalents:
- `\u2014` (em dash) vs `--` (double hyphen)
- `\u2192` (right arrow) vs `->`
- `\u2014` appears in multiple places

**Example:**
```python
# This fails because the file has \u2014, not --
content.replace("it is for human-maintained drop-offs only.", 
               "it is for human-maintained drop-offs only. **Agents should only read from mailroom/ when the user explicitly requests it.**")
```

**Files Affected:**
- AGENTS.md (contains multiple \u2014 em dashes)
- All SKILL.md files with unicode characters
- README.md (contains unicode)

**Workaround:** Read file, normalize unicode to ASCII, then write back

---

### 3. Bash Command Encoding Issues

**Error:** `Syntax error: "&&" unexpected` and similar

**Root Cause:** Shell escaping issues when passing complex commands through tool

**Example:**
```bash
# This fails due to escaping
bash: "head -117 AGENTS.md > /tmp/part1 && cat >> /tmp/part1 << 'EOF'..." 
# Error: Syntax error: "&&" unexpected
```

**Workaround:** Use python scripts for complex file operations

## Recommended Patches/Workarounds

### Patch 1: Normalize Unicode Before Editing
```python
# Always normalize unicode when reading files
import unicodedata

def read_file_normalized(path):
    with open(path, 'r', encoding='utf-8') as f:
        content = f.read()
    # Normalize unicode characters to ASCII equivalents
    content = content.replace('\u2014', '--')  # em dash to double hyphen
    content = content.replace('\u2192', '->')  # right arrow to ASCII
    content = content.replace('\u2013', '-')   # en dash to hyphen
    return content
```
